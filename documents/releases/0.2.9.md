# Cirno 0.2.9

## Complete setup catalogue and compatible Python dependencies

`cirno-setup +all --verify` installs and verifies every built-in component and its dependencies. `+all` aliases `+presets.all`; the preset discovers the catalogue automatically, so new recipes are included without another package list. It is primarily intended for Actions verification. `+rachebtms` retains its existing selection, and the published container remains a minimal unified image.

Setup adds curated support for HTTPX, YouTube Transcript API, Marker/PyTorch, Beautiful Soup, Python-Markdown, CairoSVG, sshpass and Manim. The rendering recipes reuse common Cairo/Pango build requirements, fonts, FFmpeg and LaTeX. Distribution-name aliases map to the same recipe. Python installation through uv considers the already selected roots in each environment, so compatible older versions can be chosen instead of silently breaking previously selected tools.

Setup uses uv’s automatic PyTorch backend selection, which selects the matching accelerator or CPU-only packages on machines without a supported GPU. `UV_TORCH_BACKEND` can override that choice.

AMD64 and ARM64 image checks install `+all --verify` after the existing base, research-preset and recreation checks. They check Python dependency consistency and optional commands, exercise HTTP/HTML/Markdown/SVG operations offline, and render a Manim scene containing text and a LaTeX formula. Marker model weights and inference backends are not downloaded by these checks.

## Mobile input and saved message edits

The mobile workbench hides its tab strip and Launcher while the software keyboard is open. Their restoration waits for keyboard dismissal, keeping Send/Save/Cancel buttons stable through focus changes. Editing an older message in a narrow pane hides the main composer while retaining its draft; saving or cancelling restores it.

Editing a saved human turn now atomically saves the replacement display input alongside the history rewind and pending execution. All viewers receive that input before model execution is queued. This fixes missing edited prompts and preserves input/reply ordering when a fast reply arrives before the edit acknowledgement. Editing or resetting also exits an older history window so the rewritten conversation is shown. Attachments are retained; previous tool side effects are not undone.

## Settings navigation

Leaving settings waits for pending saves and the restart decision before switching the selected tab or pane. Choosing Restart later returns to the requested conversation while retaining the pending-restart status. The retired back-to-chat buttons have been removed from both desktop and compact settings navigation.

## Upgrade

Use `ghcr.io/rachebtms/cirno:0.2.9` and retain the existing instance mounts. The 0.2.8 → 0.2.9 migration updates `lastRunVersion` while preserving configuration, conversations, profiles, memory and credentials. Earlier supported versions continue through the existing migration chain. See [Docker deployment](../docker.md), [setup selectors](../setup.md) and [migration details](../migrations.md).
