# Cirno 0.2.7

## Consolidation and memory recovery

- Retry saved consolidation results independently. One invalid batch no longer blocks unrelated batches, and failed attempts rotate so older work can progress. The browser refreshes committed results and reports partial failures without making another model request.
- Completed receipt files repair a stale status index without reapplying profile edits. Concurrent saves of the same archive share receipt ownership and preserve the completed plan.
- Checkpoint identities survive short-term journal retention. A retry of an indexed checkpoint keeps its original cursor instead of creating a duplicate event.
- Memory relations recheck both endpoint revisions inside the write transaction, rejecting evidence changed by a concurrent update.
- The embedding deadline covers model fingerprinting, query/indexing batches and cached-vector scoring, with the existing visible BM25 fallback on timeout.
- Azure credential cleanup errors are surfaced after the other provider resources are closed.

## Full-image dependencies

Go builds `xurl` in a separate stage; the runtime retains the executable and license notices without the compiler. The full image no longer preinstalls pipx, Bun, the independent Hugging Face CLI environment or Manim. The tokenizer's required Hugging Face Python SDK remains installed, with its unused command entry points omitted.

Azure, Bedrock and Olostep extras are installed on demand or through explicit build arguments. Memory embeddings and Telegram dependencies remain preinstalled.

C/C++ build tools and development headers remain available for Python extensions. `gog`, `xurl`, `tea`, `summarize`, LibreOffice, Chromium, Playwright and the document/PDF libraries remain included. LaTeX retains recommended fonts, extra macros and scientific/algorithm packages, with `latexmk` and BibTeX paper-compilation checks replacing the Manim rendering check. Venue-specific template files must accompany the paper.

Runtime Python creation, dependency installation and ownership changes share one image layer to avoid duplicating the installed environment. Multi-channel installation now stops on any failed dependency installation.

## Upgrade and validation

The new 0.2.6 → 0.2.7 migration advances `lastRunVersion` while retaining owner configuration, conversations, profiles and credentials. The existing migration chain still supports 0.1.6 and earlier 0.2.x releases. Preserve the instance volume and workspace mounts when replacing the container.

Development validation covered the complete backend/frontend suites, focused recovery/concurrency regressions, browser memory/keyboard/provider checks, static checks and the frontend build. The separate Go stage built on ARM64, and its executable ran in Ubuntu without Go. Linux media checks covered Office conversion, spreadsheet recalculation, Chinese browser rendering and scientific LaTeX/BibTeX compilation using the existing full-image environment with the retained paper packages.

The complete revised full image and its size reduction were not measured locally. The publishing workflow builds and smoke-tests both image variants on native AMD64 and ARM64 runners before publishing their manifests.
