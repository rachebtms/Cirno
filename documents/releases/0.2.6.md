# Cirno 0.2.6

## Context consolidation and learning

Context checkpoints, memory organization and verified Skill improvements now share one context-consolidation request. Active, idle and manual consolidation use the same flow, finish before the owning task resumes and do not start an additional concurrent model task. Settings and documentation use Context consolidation; legacy compaction/Dream configuration and commands remain accepted through compatibility paths.

Requests retain the original history/tool prefix for provider caching. Learning uses bounded, quoted evidence and existing visibility scopes. Shared identity/user-profile edits require explicit user evidence; autonomous Skills require verified recurring experience. File changes retain revision checks and Skill history.

Generated results survive interrupted commits. Retrying the same archive reuses its output, skips completed learning and avoids duplicate journal entries. Journal retention waits until exact events are mirrored in memory, rather than waiting for the retired idle-Dream cursor. Original evidence remains available.

## Memory cloud

The Launcher gains a singleton Memory tab with a three-dimensional relationship graph, the existing keyword/vector/hybrid search filters and the version/source inspector. Settings retains profile editing and index maintenance, with a shortcut to the tab.

Nodes reflect memory records and shared tags; stored relations connect records. Positions use a force-directed layout, so proximity is not a semantic similarity score. Pages and graph size are bounded. Rendering loads on demand, pauses while hidden and follows the actual pane size, including desktop splits and mobile restoration. A results list remains available when WebGL cannot start.

## Retrieval, tool execution and privacy fixes

- Local embedding memory budgets can exceed 200 MiB. Limit errors include the configured budget; the default remains 200 MiB.
- One embedding time budget covers query embedding and all indexing batches. Local pipe backpressure and partial output cannot bypass it. API requests receive the remaining budget, and the browser waits long enough for retrieval or its visible BM25 fallback.
- Router PTC programs share cumulative execution time across rounds. Nested calls count once; direct replies and delegation remain available after exhaustion.
- Streaming tool calls are kept separate using explicit indices/call IDs. Ambiguous streams and malformed JSON are reported without guessing or executing repaired arguments.
- Agent-facing SSH Node metadata excludes authentication values, environment values, identity-file paths and raw job command/output history. Encrypted credential values remain owner-only.
- Cancelled Launcher/tab drags no longer swallow the next click, and another pointer cannot terminate the active drag.
- Compact chat editors retain a 16 px minimum while respecting larger reading sizes and pane width.

## Full-image tools

The full image adds NumPy, Pillow, Matplotlib, PyMuPDF, Manim and Playwright alongside the existing document/PDF libraries. It includes headless LibreOffice Writer/Calc/Impress, Chromium, CJK fonts and LaTeX/dvisvgm rendering dependencies. Image-provided packages remain separate from the service environment and available to the persistent Agent Python environment. Upstream licenses are retained; see [third-party notices](../../THIRD_PARTY_NOTICES.md).

## Upgrade and validation

Startup adds the 0.2.5 → 0.2.6 version step, preserving configuration, conversations, profiles and credentials. Older supported versions follow the existing chain, including 0.1.6. Keep the instance volume and workspace mounts when replacing the container. See [instance upgrades](../migrations.md).

The implementation passed 8,532 backend tests and 3,053 frontend tests before the version update. The browser suite covered 611 checks, with failing checks corrected and rerun successfully. Release verification additionally covers the new migration step, package/version alignment and the frontend build. Ruff, import boundaries, frontend type checking and lint passed. Strict Python typing still reports annotation diagnostics and is not claimed as clean.

Keyboard browser checks simulate the visual-viewport contract in Chromium and WebKit; they do not replace a physical iPhone keyboard check. Full-image media checks ran natively on ARM64 during development; AMD64 validation belongs to the container workflow.
