# Cirno Web

Cirno's browser application uses React 19, TypeScript, Tailwind CSS 4 and HeroUI 3. Feature modules own their state, actions and views. The workbench hosts multiple conversation and resource tabs, with the same launcher on desktop and mobile. Snow themes and owner preferences synchronize through the server.

Run `npm ci`, `npm run dev`, `npm run typecheck`, `npm test` or `npm run build` in this directory. Cirno Server serves the production assets.

See [source layout](../../documents/development/source-layout.md).
